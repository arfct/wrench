A Wrench Menu is a Chrome extension that adds a menu of small tab and window commands, among them Copy Link with Title, Pop Out Video, Merge All Windows and Sleep Background Tabs. Each is implemented in as little code as possible, many in a couple of lines. It has no tracking, no spam and no advertising.

The set of commands has grown since 2021; a command is added when it has proved useful.

Chrome extension, Manifest V3.
